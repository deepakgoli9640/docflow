What the collection does for you

Four things you never do by hand

TokensA script fetches the operations and hospital tokens when a request needs one, and renews them before they expire.
Idempotency keysMoney-moving requests send a fresh key, or a saved one when the point is to show a safe retry.
Ids carry overEach response's id is saved for the next requests, so send requests in order.
ChecksEvery request tests its own result. Open the Test Results tab after sending.
HospitalhospitalToken
From the hospital's API key. Its own payments, refunds, disputes, transactions and settings. Never another hospital's data.
OperationsopsToken
From the ops-console client. Activates and suspends hospitals, ledger, reconciliation, failed notifications, dead letters.

After one full pass

Ideas to explore

Break idempotency on purposeSend B1 twice quickly with the same key, then once with a different amount.
Use up the attemptsDecline the same payment three times (B10) and watch it become FAILED.
Hit the daily limitSet dailyLimit to ₹3,000 (A6) and create payments until 422 DAILY_LIMIT_EXCEEDED.
One attempt onlySet maxAttempts to 1 (A6) and decline once: FAILED at once, and Mailpit shows “Payment not completed”.
Survive a Kafka outagedocker compose -f deploy/docker-compose.yml pause kafka, pay a payment, unpause, and watch folders E and F catch up.
Read every fieldSwagger for each service: localhost:8081/swagger-ui.html (merchant) to 8086 (reconciliation).
When something fails

Troubleshooting

401 everywhereSelect the HPG local environment and check opsClientSecret is set. It comes from deploy\env\.env: run import-postman.bat again after start-hpg.bat has created that file.
403 MERCHANT_NOT_ACTIVE on B1Run A2 first, or wait a few seconds after it.
404 on a {{…}} idAn earlier request did not save it. Send the folder again from its first request.
Settlement upload failsPick samples\settlement\discrepancies.csv by hand in the request's Body tab.
Anything elseNote the request name, errorCode and correlationId from the Postman Console, then search the logs:
docker compose -f deploy/docker-compose.yml logs | findstr <correlationId>
Matches postman/HPG.postman_collection.json and docs/postman-guide.md on master. Payments use the simulated provider: no real money moves.
