What do I type here?
  • Hospital staff: an API key id (hpgk_…) and its secret, from registration or the API keys page.
  • Operations: the ops client id and secret (HPG_OPS_CLIENT_SECRET in deploy/env/.env).

Signing in is a real OAuth2 client-credentials exchange against the gateway: if it returns a token, the credentials are valid, and the token says which role you have. The console keeps no user accounts of its own. In a real deployment people would sign in through an identity provider with multi-factor authentication, and API keys would stay in servers.
